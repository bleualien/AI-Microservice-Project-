# 🏋️ AI-Powered Fitness Application

An intelligent, full-stack fitness application built using **Spring Boot Microservices, Spring Cloud, Apache Kafka, MongoDB, PostgreSQL, Keycloak, and React/Angular**.

The application enables users to track their fitness activities, manage workout information, and receive personalized AI-powered fitness recommendations using Generative AI (Google Gemini / OpenAI).

Built with a scalable microservices architecture, the platform demonstrates modern backend engineering practices, event-driven communication, centralized configuration, service discovery, and secure authentication.

### Key Features

- 👤 User Registration & Profile Management
- 🏃 Fitness Activity Tracking
- 📊 Workout and Activity Management
- 🤖 AI-Powered Fitness Recommendations
- 🧠 Personalized Recommendations Using Generative AI
- ⚡ Asynchronous Communication with Apache Kafka
- 🔍 Service Discovery with Netflix Eureka
- 🚪 Centralized API Routing with Spring Cloud Gateway
- 🔐 Secure Authentication with Keycloak and OAuth2
- 🗄️ PostgreSQL & MongoDB Integration
- 🌐 Interactive Frontend with React/Angular

### Technology Stack

**Backend:** Java, Spring Boot, Spring Security, Spring Cloud

**Microservices:** Eureka Server, Config Server, API Gateway

**Databases:** PostgreSQL, MongoDB

**Messaging:** Apache Kafka, Spring Kafka

**AI Integration:** Spring AI, Google Gemini / OpenAI

**Security:** Keycloak, OAuth2, OpenID Connect, JWT, PKCE

**Frontend:** React / Angular, JavaScript / TypeScript

### Architecture

The application follows a microservices architecture with independent services for user management, fitness activity tracking, and AI-powered recommendations.
